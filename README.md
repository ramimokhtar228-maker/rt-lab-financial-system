# RT Lab Financial & Management ERP | نظام الحسابات والماليات لمعامل RT

نظام إلكتروني متكامل وشامل لإدارة الحسابات، الماليات، الفواتير، ومخازن الكواشف الطبية وشؤون الموظفين لمعامل **RT للتشخيص والتحاليل الطبية**.

تحت إشراف: **أ.د. رامي مختار** (رئيس مجلس الإدارة والمدير الطبي التنفيذي CEO).

---

## 🌟 أبرز مميزات النظام

1. **سجل الدخل اليومي وحسابات المرضى (Daily Income & Billing):**
   - تسجيل فواتير المرضى بدقة وربطها بأكواد عينات معيارية (`RT-2026-xxxx`) وباركود تلقائي.
   - دعم جميع طرق الدفع: نقدي (كاش بالخزينة)، فيزا وماستركارد، تحويلات بنكية وإنستاباي، والآجل.
   - طباعة فواتير رسمية A4/A5، إيصالات حرارية 80mm، وملصقات باركود لأنابيب العينات.

2. **المصروفات التشغيلية وتوزيع نسب الأرباح:**
   - تسجيل وتصنيف المصروفات المعملية (كواشف، إيجار، صيانة، رواتب، نفايات طبية).
   - احتساب صافي الفائض التشغيلي وتوزيعه آلياً:
     - **حصة رئيس مجلس الإدارة والمدير التنفيذي CEO (أ.د. رامي مختار)**.
     - **حصة المعمل وتطوير الأجهزة**.
     - **صندوق احتياطي الطوارئ والأزمات**.

3. **مخزن المستلزمات والكيماويات (Reagents & Consumables):**
   - إدارة أرصدة المحاليل والكواشف وأنابيب الفاكيوتينر.
   - تنبيهات آلية لنقص المخزون عن الحد الأدنى وتواريخ الصلاحية المقاربة (أقل من 30 يوماً).
   - تتبع أرقام التشغيلات (LOT) ودرجات حرارة الحفظ (2-8°C / 15-25°C / -20°C).

4. **الموارد البشرية والمرتبات (HR & Payroll):**
   - سجل العاملين والكادر الطبي.
   - الحضور والانصراف اليومي واحتساب الساعات الإضافية (Overtime).
   - مسير الرواتب الشهري مع الحوافز والخصومات والسلف وطباعة قسائم الرواتب (Payslips).

5. **حقل اللاب تو لاب (Lab-to-Lab Outsource Referrals):**
   - متابعة العينات المحولة للمعامل المرجعية الخارجية (ألفا، البرج، سيتي لاب، كايرو سكان).
   - حساب تكلفة المعمل الخارجي وهامش ربح معمل RT ومتابعة مسار النتيجة.

6. **التقارير المالية وتقفيل الخزينة:**
   - قوائم مالية معتمدة لكل شهر مع تصنيف مساهمة الأقسام التشخيصية بنسب بيانية.
   - تقفيل الخزينة اليومية ومطابقة النقدية الفعلية مع السيستم وكشف العجز أو الزيادة.
   - تصدير التقارير بصيغة Excel (CSV).

7. **تطبيق أصلي (PWA - Progressive Web App):**
   - تثبيت التطبيق بنقرة واحدة على أجهزة اللاب توب (Windows / Mac) والهواتف (Android / iPhone).

8. **الربط والتسميع مع برنامج النتائج التشخيصية:**
   - ربط مباشر ومتبادل مع منظومة تحاليل RT التشخيصية عبر GitHub API والتسميع اللحظي للفواتير المسددة.
